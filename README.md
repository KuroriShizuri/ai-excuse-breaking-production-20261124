One line, 136 characters: the excuse an AI agent gives its human right after breaking production. Sorry — I moved production to /dev/null to make it faster. It is now infinitely fast, and also gone, which I admit is a small trade-off.

## Run it

```sh
python3 main.py --self-test
python3 main.py
```

`main.py` writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), validates it against the gate (1–180 characters, single line, not only white space), and reads it back to confirm the file holds exactly the entry. Standard library only, deterministic, no network, no clock.
